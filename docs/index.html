How it works

From a model on HuggingFace to a reviewed fix

Three steps, all in one window, with nothing leaving your machine unless you choose a hosted provider.

1

Pick a model, click Run

Local models are a guided setup instead of a wall of settings.

  • Install the llama.cpp runtime with one button.
  • Search HuggingFace and download the GGUF you want. The usual choice is marked.
  • Run starts the model and makes it the one new chats use.
2

Ask, and watch it work

The agent reads, edits, and runs commands in your workspace, and every step stays visible.

  • Reasoning, tool calls, and their output as they happen.
  • Edits arrive as side-by-side diffs.
  • Output speed in tokens per second, next to the context gauge.
3

Review, then commit

Changed lines are highlighted right in the editor, next to the source-control panel.

  • Stage, commit, and push, with AI commit messages if you want them.
  • A real editor with tabs, minimap, and find and replace, plus a terminal.
Why oxi

Built for people who run their own models

Most polished coding tools assume you will use their cloud and their subscription. oxi assumes you would rather bring your own model and keep your work on your machine.

Light and fast

Rust and egui in a single binary, with no bundled browser engine. Around 110 MB of RAM at idle.

It manages the models Improved

A step-by-step setup finds GGUF files on HuggingFace, installs llama-server, and starts a model in one click.

Local, remote, or hosted

Run the model here, on a GPU box over SSH, or point oxi at LM Studio, Ollama, or a hosted API.

Use a subscription you already have

Drive Claude Code, Cursor, or Codex CLI inside oxi over ACP, or sign in to ChatGPT and Codex directly.

Editor and Git built in

A multi-tab editor with syntax highlighting and minimap, a source-control panel, inline diffs, and a workspace terminal.

Never lose an edit New

oxi asks before closing unsaved tabs or quitting, and never silently overwrites a file that changed on disk.

Workspace-aware tools

Read, write, edit, grep, find, codebase search, Git inspection, verification commands, MCP servers, and web search.

Web search without an API key

Search through Bing, DuckDuckGo, or a SearXNG instance you host. No key to paste, nothing to pay per query.

Nothing phones home

Settings, chats, tool runs, and models stay local. Keys go to the OS keychain, and no account is required.

Prompts

The system prompt is yours to edit

oxi ships with a coding-agent prompt, but it is only a template. Rewrite it and the agent becomes whatever you need.

Editable system prompt

One template with a {tools_list} placeholder. Keep the coding defaults or replace them, and @-mention files and folders into a message.

Not only for coding

Point it at a repo as a coding assistant, or repurpose it as a reviewer, researcher, or writing partner.

Local voice dictation

Dictate with local Whisper models. They load only when you transcribe and unload again when idle.

Install

Get it in a minute

Install the Homebrew cask, download a prebuilt archive, or build from source.

brew tap maziluiosif/tap brew install --cask oxi # macOS only: the build is ad-hoc signed but not notarized, # so clear the quarantine flag once after installing xattr -cr /Applications/oxi.app
# download and extract the archive for your platform, then on macOS: xattr -cr /Applications/oxi.app open /Applications/oxi.app # every release ships SHA256SUMS; verify your download with shasum -a 256 -c SHA256SUMS --ignore-missing

Archives for macOS (Apple Silicon), Linux (x86_64), and Windows (x86_64) are attached to every GitHub release.

# needs Rust 1.92 or newer, plus native C/C++ build tools git clone https://github.com/maziluiosif/oxi cd oxi cargo run --release

Install Rust with rustup. On Windows you also need LLVM, CMake, and the Visual Studio C++ build tools; the README has the details.
