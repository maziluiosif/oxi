How it works

From install to a reviewed fix in five minutes

Everything happens in one window. Nothing leaves your machine unless you choose a hosted provider.

1

Pick a model

Local models are a guided setup, not a wall of settings.

  • Free and private: install the llama.cpp runtime with one click, download a GGUF from HuggingFace, click Run.
  • Already subscribed? Make Claude Code, Codex or Cursor active. They use your existing login.
  • Have a key? OpenAI, OpenRouter, Azure, Anthropic-compatible and more.
2

Ask, and watch it work

The agent reads, edits and runs commands in your workspace, and every step stays visible.

  • Reasoning, tool calls and their output as they happen.
  • Edits and shell commands can ask for your approval first.
  • Type /plan to investigate before changing anything.
3

Review, then commit

Every change opens in a real diff editor, next to the Git panel.

  • Side by side or inline, and editable in place.
  • Stage or discard any block with one click.
  • Commit and push, with AI-written messages if you want them.
Why oxi

Your model, your machine, your workflow

Most coding tools assume their cloud and their subscription. oxi lets you bring your own.

It runs the models for you

Find a GGUF on HuggingFace and click Run. oxi installs llama-server and starts the model, here or on a GPU box over SSH. LM Studio and Ollama work too.

Use the subscription you have

Drive Claude Code, Codex or Cursor inside oxi over ACP, or sign in with ChatGPT. The Router picks a provider per task and switches when a quota runs out.

Review like in your editor

An editable diff editor with word highlights and block staging, plus tabs, go to definition, find and replace, a minimap and a terminal.

Plan first, then build

/plan investigates without touching a file and keeps a live checklist. One click turns the plan into changes.

Light and fast

One native binary, no bundled browser. Around 110 MB of RAM at idle, and a frame of a long chat draws in about a millisecond.

Nothing phones home

Chats, settings and models stay on your machine. Keys go to the OS keychain. Web search and voice dictation work without extra keys.

Install

Get it in a minute

One command on macOS, Linux or Windows. Run it again to update.

# macOS (Apple Silicon) and Linux (x86_64) curl -fsSL https://maziluiosif.github.io/oxi/install.sh | sh # Windows (x86_64), in PowerShell irm https://maziluiosif.github.io/oxi/install.ps1 | iex

Then run oxi in a project folder, or open it from your apps menu. oxi update updates it.

brew tap maziluiosif/tap brew install --cask oxi # macOS only, once after installing xattr -cr /Applications/oxi.app
# macOS: after moving oxi.app to /Applications xattr -cr /Applications/oxi.app # Windows: first launch, click More info → Run anyway

Get the archive for your platform from the latest release.

# needs Rust 1.92 or newer, plus native C/C++ build tools git clone https://github.com/maziluiosif/oxi cd oxi cargo run --release

Install Rust with rustup. On Windows you also need LLVM, CMake, and the Visual Studio C++ build tools; see the README.

FAQ

Good questions

Is it really free?

Yes. oxi is MIT licensed and has no account, no telemetry and no paid tier. You only pay for a hosted model if you choose one; local models cost nothing.

Does my code leave my machine?

Not with a local model: the model, your chats and your settings all stay on your computer. With a hosted provider, the prompt and the files the agent reads go to that provider, as with any coding assistant.

Do I need a GPU?

No. Apple Silicon Macs run 7B to 14B coding models well. On a laptop without a strong GPU, run the model on another machine over SSH with Remote HF, or use a hosted provider.

I already pay for Claude Code, Codex or Cursor. Why use oxi?

oxi drives them over ACP with your existing login, and adds a desktop UI around them: the diff editor, Git, plan mode with a checklist, and a Router that can switch to a local model or another subscription when a quota runs out.

Why does macOS or Windows warn about the app?

The app isn't signed with a paid Apple or Microsoft certificate. The one-line installers avoid the warning; with a manual download, run xattr -cr /Applications/oxi.app on macOS, or click More info → Run anyway on Windows.

Is the agent safe to let loose?

File edits and shell commands can ask for approval first, and that prompt is the real safety boundary: commands and MCP tools are not sandboxed. Plan mode lets the agent investigate without changing anything.
